# Cara Baca & Verifikasi Dokumen PBB - Anti Hoax

Repo ini pakai **dokumen primer resmi PBB**. Bukan dari berita, bukan dari Instagram. Ini cara cek keasliannya biar gak dibilang hoax.

## 1. Kenali Kode Dokumen PBB

Setiap dokumen PBB punya kode unik:

- **S/2023/130** = Security Council, tahun 2023, nomor 130 -> Laporan Panel Ahli Yaman
- **A/HRC/55/67** = General Assembly / Human Rights Council, sesi 55, nomor 67 -> Laporan Iran demo 2022
- **A/HRC/41/CRP.1** -> Laporan Khashoggi
- **UNDP YEMEN 2021** -> Laporan 377.000 mati Yaman

Kalau ada kode ini, 99% asli.

## 2. Cara Verifikasi 3 Langkah (30 Detik)

**Langkah 1: Cek Domain**
File asli harus dari:
- `un.org`
- `ohchr.org`
- `undp.org`
- `securitycouncilreport.org` (mirror resmi Dewan Keamanan)

Kalau dari `randomblog.com` = bukan primer.
