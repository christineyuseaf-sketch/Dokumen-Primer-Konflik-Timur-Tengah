# Dokumen Primer Konflik Timur Tengah - Anti Hoax

Repo ini berisi **PDF ASLI dari PBB** (bukan media). Tujuannya untuk meluruskan propaganda di Instagram/TikTok tentang jumlah korban di Yaman, Suriah, Iran.

**Semua file bisa diverifikasi di domain resmi: un.org, ohchr.org, undp.org**

## Daftar Isi & Temuan Kunci

### 01_YAMAN - Korban Saudi
- **Temuan:** 377.000 mati sampai akhir 2021 (UNDP 2021, Halaman 12). 70% Sunni.
- File: `01_UNDP_377k_Deaths_2021.pdf`

### 02_SURIAH - Bantah Propaganda Iran 500rb
- **Temuan:** Total mati Suriah 306.000 (UN OHCHR 2022). Tangan Iran langsung cuma 1.800 (SNHR 2023 - oposisi Suriah).
- File: `01_UN_OHCHR_306k.pdf` & `02_SNHR_Iran.pdf`

### 03_IRAN_DALAM_NEGERI - Bantah 500rb Demonstran
- **Temuan:** Demo Mahsa Amini 2022 cuma 551 mati (UN Fact Finding A/HRC/55/67), bukan 500rb.
- File: `01_UN_A-HRC-55-67.pdf`

## Cara Verifikasi
1. Buka PDF
2. Cek kode dokumen PBB di header (contoh: S/2023/130)
3. Paste kode di Google + site:un.org
