# Dokumen Primer Konflik Timur Tengah - Anti Hoax

Repo ini berisi **PDF & DATA ASLI** untuk meluruskan propaganda di Instagram/TikTok tentang jumlah korban di Yaman, Suriah, Iran. **Bukan opini media, tapi dokumen primer.**

### Prinsip Anti-Hoax
1.  **Dokumen PBB (un.org, ohchr.org, undp.org) = Taruh di `01_Dokumen_PBB` & `02_`, `03_`**. Bisa diverifikasi dengan kode dokumen (Contoh: S/2023/130 -> paste di Google `site:un.org`)
2.  **Data NGO Verifikasi (YDP, SNHR) = Taruh di `03_Data_Non-PBB`**. Dipisah jelas, bukan diklaim sebagai PBB.

## Cara Verifikasi (Biar Gak Dibilang Hoax)

**Untuk Dokumen PBB:**
1. Buka PDF
2. Cek kode dokumen PBB di header (contoh: `S/2023/130`, `A/HRC/55/67`, `A/48/949`)
3. Paste kode di Google dengan format: `S/2023/130 site:un.org` atau `A/HRC/55/67 site:ohchr.org`

**Untuk Data NGO:**
1. Cek folder `03_Data_Non-PBB`
2. YDP cek langsung ke yemendataproject.org
3. SNHR cek ke snhr.org

> Catatan: Repo ini untuk edukasi & fact-checking. Tidak berafiliasi dengan pemerintah manapun. Dokumen PBB dan NGO dipisah dengan jelas untuk transparansi.
