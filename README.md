# Dokumen-Primer-Konflik-Timur-Tengah
Kumpulan dokumen primer resmi PBB (UNDP, OHCHR, UN Panel of Experts), Amnesty, dan SNHR tentang korban konflik di Yaman, Suriah, Iran, Bahrain, Sudan. Semua sumber dari domain resmi un.org &amp; ohchr.org. Anti-hoax, anti-propaganda. Untuk edukasi &amp; fact-checking.
